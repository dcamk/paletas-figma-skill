# Paletas de cores (Figma)

Fonte: https://www.figma.com/pt-br/resource-library/combinacoes-de-cores/ (copiado em 05/11/2026).
Os HEX são os rótulos oficiais impressos em cada paleta. Em algumas imagens, a faixa de cor mostrada difere um pouco do rótulo; aqui vale o rótulo.
Exceção: na 22, o rótulo da 4ª cor vem com erro na fonte ("#CC550"), então usei a cor da faixa.

## Como usar

1. Ache pelo clima ou pelo setor na coluna "uso" (busque palavra-chave: fintech, infantil, luxo, verão, modo escuro...).
2. A ordem é a da fonte, não um papel fixo. Defina os papéis olhando a luminância: a mais escura para texto/fundo escuro, a mais clara para fundo, a mais saturada para destaque/CTA, a restante para superfícies e bordas.
3. Confira contraste WCAG (texto ≥ 4.5:1). Várias paletas pastel/neon não têm par legível entre si; complete com quase-preto (#111) ou quase-branco (#FAFAFA).
4. Pode ajustar luminosidade em OKLCH para criar tons intermediários (hover, bordas), mantendo o matiz.
5. Diga ao usuário qual paleta usou (número + nome).
6. Se o projeto já tem design system próprio (Black Glass, Fio Vermelho, kit dos afiliados), ele vem antes. Use estas paletas só quando ele pedir cor nova ou não houver sistema.
